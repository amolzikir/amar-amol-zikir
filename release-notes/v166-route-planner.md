# v166 — যাতায়াতের রুট

- প্রধান মেনুর “যাতায়াতের রুট” থেকে শুরুর স্থান ও গন্তব্য লিখে Google Maps Directions খুলুন।
- GPS ব্যবহার করতে “বর্তমান লোকেশন নিন” চাপুন এবং ব্রাউজারের অনুমতি দিন; অনুমতি না দিলে শুরুর স্থান হাতে লিখুন।
- গাড়ি, হাঁটা বা গণপরিবহন বেছে নেওয়া যায়। গণপরিবহনের রুট Google Maps-এর ওই এলাকার তথ্যের ওপর নির্ভরশীল।
- লোকেশন ও যাত্রার তথ্য অ্যাপে সংরক্ষণ হয় না; রুট খোলার সময় Google Maps-এ পাঠানো হয়।
- কোনো Maps API key বা paid API ব্যবহার করা হয়নি।
